# Storage_MarivanFardamentos
O projeto consiste no desenvolvimento de um sistema de controle de estoque para a Marivan Fardamentos. A aplicação permitirá cadastrar produtos, registrar entradas e saídas, consultar a disponibilidade em tempo real e gerar relatórios. O objetivo é organizar o estoque, reduzir erros, otimizar a gestão e agilizar o atendimento aos clientes.
